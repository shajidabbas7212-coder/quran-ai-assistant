# 🕌 Quranic AI Assistant

**قرآن سے ہر سوال کا جواب**

ایک ذہین AI assistant جو صرف قرآن مجید سے جوابات دیتا ہے۔

## 📱 خصوصیات (Features)

- ✅ قرآن مجید سے براہِ راست جوابات
- ✅ اردو اور انگریزی میں دستیاب
- ✅ تفسیر اور ترجمہ کے ساتھ آیات
- ✅ Web Platform + Mobile App
- ✅ مکمل طور پر مفت اور حلال

## 🚀 شروع کریں

### ضروریات (Requirements)
- Python 3.8+
- Node.js 14+
- Firebase (مفت account)

### Installation

```bash
# Repository کو clone کریں
git clone https://github.com/shajidabbas7212-coder/quran-ai-assistant.git
cd quran-ai-assistant

# Dependencies انسٹال کریں
pip install -r requirements.txt
npm install
```

### چلائیں (Run)

```bash
# Backend شروع کریں
python app.py

# Frontend شروع کریں (دوسری ٹرمنل میں)
npm start
```
